### 2. BrightWeb Crafters Connect
A full-stack educational content marketplace that connects **learners** with **content creators**, while **admins** manage the entire ecosystem. Built with **ASP.NET Core MVC (.NET 8)** and **Bootstrap 5**, featuring role-based dashboards, a dark mode theme, and a public store.

**Application Features**
- **Dark Mode:** Toggle in the navbar switches between light and dark themes. Preference is saved in `localStorage`.
- **Role-Based Experiences:**
  - **Admin:** Full management sidebar with promotions, user management, records, content management, and audit logs.
  - **Content Creator:** Dedicated creator sidebar with dashboard, content creation, analytics, earnings, and profile settings.
  - **Learner / Guest:** Clean, full-width public experience with store, cart, and profile.
- **Public Store:** Browse content, manage a cart, and view purchases.
- **Authentication:** Built with **ASP.NET Core Identity** — role-based registration and guarded routes.
- **Stack:** ASP.NET Core MVC (.NET 8) · Entity Framework Core · SQLite · Bootstrap 5.3 · Font Awesome 6 · Docker
- **Link:** [https://github.com/BRIGHTWEBCRAFTER/BrightWeb-Crafters-Connect](https://github.com/BRIGHTWEBCRAFTER/BrightWeb-Crafters-Connect)
